Política de privacidad de DriveTV

Última actualización: 25 de octubre de 2026

Qué datos usa

DriveTV accede a Google Drive con el permiso de solo lectura https://www.googleapis.com/auth/drive.readonly para mostrar los nombres, miniaturas y metadatos de carpetas y vídeos, y para reproducir esos vídeos en el televisor.

Dónde se guardan

Los datos de Google Drive se leen directamente desde los servidores de Google hacia el televisor del usuario y no se almacenan fuera de él. El token de acceso se guarda únicamente dentro de la aplicación instalada en el televisor del propio usuario.

Con quién se comparten

Con nadie. DriveTV no tiene servidores propios, no usa analíticas ni publicidad y no transfiere, vende ni comparte datos de usuario con terceros.

Uso de los datos de Google

El uso de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

Puedes retirar el acceso en cualquier momento desde myaccount.google.com/permissions.
